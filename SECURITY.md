# Security Policy

## Supported versions

This repository tracks the `main` branch as the supported line for security fixes.

## Reporting a vulnerability

Please **do not** open a public Issue for security reports that include exploit details or secrets.

Prefer one of the following (in order):

1. **Private vulnerability reporting** on this repository (Security → Report a vulnerability), if available to you
2. GitHub Security Advisories for this repository (Security → Advisories → New draft security advisory), if available to you
3. Contact the repository owner via GitHub (profile or private contact linked from the owner account)

Include:

- Affected component (web app, Cloud Functions, docs, CI, etc.)
- Impact and a minimal reproduction if safe to share
- Whether you believe secrets or personal data were exposed

You should receive an initial response within 7 days. Please allow time for triage and a fix or mitigation before any public disclosure.

## Non-security bugs

Use regular GitHub Issues for product bugs that are not security vulnerabilities.
