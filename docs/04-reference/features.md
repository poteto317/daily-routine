## コア機能

### 🔄 ルーティン管理

日々の習慣をルーティンとして登録・管理する、本アプリのメイン機能です。

**主な機能**

- ルーティンのCRUD操作（作成・読み取り・更新・削除）
- 時間ベースの管理（開始時間を設定して時系列表示）
- 曜日別・祝日別のルーティン設定
- カテゴリ分類（仕事/健康/趣味/勉強/生活/その他）
- ドラッグ&ドロップによる順序変更（ドラッグハンドル方式）
- チェックボックスで達成状態を記録
- 週1〜7回の週間目標を任意で設定
- 同じルーティンを複数曜日に登録している場合、週間目標をグループ全体へ反映
- 日付が変わると自動的にチェックがリセット
- プッシュ通知機能（BETA版・不安定）

**設定項目**

- タイトル（必須）
- 開始時間（HH:mm形式、必須）
- 所要時間（分、必須）
- カテゴリ（必須）
- 実行する曜日・祝日（複数選択可能、必須）
- 説明（任意）
- 週間目標（週1〜7回、任意。未入力で無効）
- 通知（開始時間から何分後か、任意）※BETA版・不安定

**技術仕様**

- ファイル: `src/features/routine/`
- データ保存: LocalStorage（キー: "routines", "lastResetDate", "todayProgress"）
- Firestore同期対応
- 通知: Service Worker経由でプッシュ通知（BETA版）
- ドラッグ&ドロップ: @dnd-kit（実装済み）

### 📋 ルーティンプリセット管理

複数のルーティンをセットとして保存し、他の曜日にまとめて適用できる機能です。

**主な機能**

- 複数のルーティンをプリセットとして保存
- プリセットに名前と説明を付与
- 保存したプリセットを任意の曜日に一括適用
- プリセットの複製（コピーは元のプリセットから独立し、互いに影響しない）
- プリセットの削除

**使用例**

- 「平日モーニングルーティン」を作成し、月〜金に一括適用
- 「週末ルーティン」を作成し、土日に適用
- 既存プリセットを複製してから一部だけ変更し、別バリエーションを作成

**技術仕様**

- ファイル: `src/features/preset/`
- データ保存: LocalStorage（キー: "routinePresets"）

### 📊 統計・レポート

達成記録を週次・月次・カテゴリ別に分析・可視化します。

**主な機能**

**週次レポート**

- 週平均達成率
- 完了したルーティン数
- 総ルーティン数
- 週間目標ごとの達成回数、残り回数、進捗バー
- 現在の連続達成週数と最長連続達成週数

週間目標は月曜日から日曜日までを1週間として集計し、同じグループは1日1回まで数えます。進行中の今週が未達成でも、それまでの現在ストリークは途切れません。目標回数を変更した場合は変更時点から新しいストリークとして集計します。

**月次レポート**

- 月平均達成率
- 最高達成日
- 最低達成日

**カテゴリ別レポート**

- カテゴリごとの達成状況
- Chart.jsによるビジュアル表示
- 月ごとのカテゴリ別サマリー

**表示切替**

- 週次・月次・カテゴリ別の表示モード切替
- 期間選択（今週・今月へジャンプ）

**技術仕様**

- ファイル: `src/features/statistics/`
- データソース: LocalStorage（"achievementHistory"から算出）
- チャートライブラリ: Chart.js
- react-chartjs-2

## ライフログ機能

### 💰 家計簿 (BETA)

日々の支出を記録し、月次予算を管理します。

**主な機能**

- 支出の記録（日付・金額・メモ）
  - 支出が無かった日は、金額 0 円で記録できる（今日より前の日付のみ。「今日」は端末のローカル日付で判定する）。記録した日は、1日あたり使える金額の残り日数に含めない
- 月次予算の設定
- 月ごとの支出一覧
- 自動集計
  - 月の予算
  - 使った金額
  - 残り金額（または予算オーバー額）
  - 1日あたり使える金額（当月の未入力日数で算出。今日に入力があっても今日だけは日数に含める）
- 月の切り替え（前月・次月・今月）
- 支出の削除

**技術仕様**

- ファイル: `src/features/budget/`
- データ保存: LocalStorage（キー: "expenses", "monthlyBudget"）
- ステータス: BETA版

### ☁️ クラウド同期

Firestoreを使用した複数端末間のデータ同期機能です。

**主な機能**

- 手動同期
  - ⬆️ クラウドにアップロード
  - ⬇️ クラウドからダウンロード
- リアルタイム変更検知
  - 他の端末での変更を自動検知
  - 通知でユーザーに通知
- 同期対象データ
  - ルーティン登録データ
  - 今日の進捗データ
  - 達成カレンダー・統計データ（全履歴）
  - アプリ設定
- 同期ステータス表示
- 最終同期時刻の表示
- エラーハンドリング

**注意事項**

- アップロード時: クラウドのデータを上書き
- ダウンロード時: ローカルのデータを上書き

**技術仕様**

- ファイル: `src/features/sync/`, `src/features/settings/components/CloudSyncSection.tsx`
- サービス: Firebase Firestore
- Cloud Functions: `firebase-functions/src/sync.ts`
- リアルタイム監視: Firestoreリスナー

## 運動種目の管理とAPI

運動記録の種目は筋トレ／ランニング別のセレクトボックスから選びます。「種目を管理」から追加・名前変更・削除ができます。初期候補は空で、過去の自由入力記録はそのまま保持します。種目を改名・削除しても記録時の名前は変わりません。

種目マスターはユーザー別に保存し、クラウド同期・同期スナップショット・JSONバックアップの「記録」グループに含まれます。古い同期データで種目が欠損している場合は端末の種目を保持し、明示的な空配列は削除として反映します。

種目・運動記録の一覧・作成・更新・削除はAPIでも操作できます。詳細は [APIリファレンス](./agent-api.md#運動記録種目マスター) と [OpenAPI](./openapi.yaml) を参照してください。APIの変更をアプリへ反映するには先に同期ダウンロードを行ってください。
