## 🧪 テストの種類

### 1. 機能テスト

[test-matrix.md](./test-matrix.md) を使用して、各機能の動作確認を行います。

**テスト対象:**
- 認証機能
- ルーティン管理（CRUD、表示、通知）
- ライフログ機能（家計簿、ジャーナル、食事記録等）
- 生産性機能（ポモドーロ、作業記録）
- クラウド同期
- データ管理

### 2. 自動テスト

```bash
# ユニットテスト実行
npm test

# カバレッジ付きテスト
npm run test:ci

# ウォッチモード
npm run test:watch
```

### 3. ビルドテスト

```bash
# 型チェック
npm run typecheck

# Lintチェック
npm run lint

# ビルドテスト
npm run build
```

## 📋 テストマトリクスの使い方

### ステータス凡例

| ステータス | 意味                         |
| ---------- | ---------------------------- |
| ✅         | 実装済み                     |
| 🔶         | BETA（開発途中・不安定）     |
| 🚧         | 開発予定（未実装・実装途中） |
| ⬜         | 未確認                       |

### チェック手順

1. [test-matrix.md](./test-matrix.md) を開く
2. テスト対象の機能を選択
3. PCとスマホで動作確認
4. ステータス欄にチェック結果を記入

### 注意が必要な機能

- **🔶 通知機能**: BETA版・不安定
- **🚧 ドラッグ&ドロップ**: 開発途中

## 🔍 テスト観点

### 基本動作

- [ ] 各機能が正常に動作するか
- [ ] エラーハンドリングが適切か
- [ ] ローディング表示が適切か

### データ永続化

- [ ] LocalStorageに正しく保存されるか
- [ ] ページリロード後もデータが保持されるか
- [ ] Firestore同期が正常に動作するか

### UI/UX

- [ ] レスポンシブデザインが機能するか
- [ ] アクセシビリティが確保されているか
- [ ] エラーメッセージが分かりやすいか

### ブラウザ互換性

- [ ] Chrome（最新版）
- [ ] Safari（最新版）
- [ ] Firefox（最新版）
- [ ] モバイルブラウザ（iOS Safari、Android Chrome）
