# 月別の家計簿エクスポート設計

## 目的と範囲

Issue #218。家計簿トップで選択した月の保存済み支出を JSON ファイルに書き出す。ユーザーが JSON 形式を指定した。既存の支出・月選択・カテゴリ状態を使い、保存・同期・インポートの挙動は変更しない。未保存のフォームと収入・固定費・変動費の設定は対象外。

## 方式の比較と決めたこと

CSV は表計算向き、JSON はアプリのデータ保持に適する。ユーザー指定の JSON を採用。両形式の追加は範囲外。ブラウザ配布には既存の downloadJsonFile をそのまま再利用する。

## UI とデータ

家計簿トップの月ナビゲーション直下に「この月の支出を JSON でエクスポート」ボタンを置く。表示中の月、expenses、categories を必須 props で専用部品に渡す。未保存の編集値は含めない。月変更時は新しい月を対象にし、結果メッセージはリセットする。

ファイル名 daily-routine-budget-YYYY-MM.json。既存バックアップと同じキー名で { budgetData: { expenses: { [month]: Expense[] } }, budgetCategories: BudgetCategory[] } を出力。配列には対象月の全支出を元の順番・値のまま含め、カテゴリはその支出から参照される現存カテゴリのみ含める。0 円、未設定・削除済みカテゴリの支出も省かない。id/date/amount/categoryId/createdAt/usedTime を保持。念のため支出の日付の月でもフィルタし、別の月は含めない。元配列・オブジェクトは書き換えない。

空月は disabled にし「この月の支出の記録がありません」と案内する。ダウンロードの開始で「JSON のダウンロードを開始しました」、例外で「書き出しに失敗しました」。端末への保存完了は断言しない。本機能は月別の保存用であり新しい復元機能を約束しない（既存の設定インポートは全データ置換であり月別マージではない）。

## 構成と検証

純粋なデータ抽出と命名を budgetMonthlyExport.ts に置く。UI と結果状態は BudgetMonthlyExport.tsx。BudgetPage は既存状態を渡し key={month} で結果を初期化する。
TDD で月境界、空、0 円、参照カテゴリ、欠損カテゴリ、任意フィールド、不変性を検証。ページから実部品を通した配線、月変更、未保存編集の除外、失敗と再試行を確認する。Storybook と機能ドキュメントも更新。全体の lint/typecheck/test/build を実行。
