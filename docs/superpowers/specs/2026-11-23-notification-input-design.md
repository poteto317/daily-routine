# 通知登録の読み取り検証

現在のスケジューラが読む notificationSubscriptions の各登録を、同期 API と同じトークン・ルーティンの制約で確認する。ルーティン配列が空、または必要項目に不正な値を含む登録は処理をスキップし、後続の登録を処理する。既存の曜日・祝日互換と正常な通知の内容を維持する。配信や Firestore の障害処理は従来どおりとする。

検証に通ったデータは既存フィールドを保持する。正常・不正・正常の順に読み、前後の正常な登録だけが配信処理に進むことを確認する。参照知見は L-556 と L-017。
読み取り値は unknown として扱い、生の保存値や検証エラーはログに記録しない。
保存値の isActive は任意の真偽値として保持する。
