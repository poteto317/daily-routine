# 通知配信ログからルーティン名を除く

配信ログは固定の結果メッセージと診断用の `deliveryId` を記録する。`deliveryId` は既存の重複確認キーの SHA-256 ハッシュとし、同じ配信の成功・失敗・重複を照合できる。ルーティン名、ルーティン ID、FCM トークン、元の例外オブジェクトやメッセージは記録しない。

送信済み確認で失敗した場合は、安全な固定メッセージと `deliveryId` を持つ例外を上位に伝える。Cloud Functions が例外を記録しても、SDK 由来の内容がログに含まれない。FCM 送信失敗と送信履歴の保存失敗は別の固定メッセージとし、どちらも従来どおり false を返す。

通知本文、Firestore の重複確認キーと送信履歴、配信の戻り値は従来どおり。過去のログの保存期間や閲覧権限はこの変更の対象外とする。
