# 家計簿の Beta 表記削除（Issue #194）

## 目的

家計簿機能が正式機能になったため、利用者に表示する家計簿の Beta 表記を削除する。

## 対象

- `BudgetPage` の見出しに表示している `BETA` バッジを削除する。
- ヘッダーメニューの家計簿項目に設定している `BETA` バッジを削除する。
- テストマトリクス画面の家計簿カテゴリに設定している `BETA` バッジを、既存の正式機能と同じ「実装済」バッジへ変更する。
- `docs/04-reference/features.md` の目次にある「💰 家計簿 (BETA)」を「💰 家計簿」へ変更する。見出しを「💰 家計簿」へ、目次リンクを対応するアンカーへ更新する。
- `docs/04-reference/features.md` の家計簿セクションにある「ステータス: BETA版」を「ステータス: 正式機能」へ変更する。
- `docs/04-reference/README.md` の家計簿表記から「（BETA）」を削除する。
- `docs/03-testing/test-matrix.md` の家計簿見出しを `🔶` から `✅` に変更する。個別のテスト項目の状態は、実装完了・安定性を改めて検証する範囲ではないため変更しない。

## 対象外

家計簿以外の機能・設定・開発用の `Beta` 表記は変更しない。特に、通知の実験的機能、ポモドーロ、作業記録、運動・食事・体重記録の表記は維持する。

## 決めたこと

- 未使用になる `budgetTexts.page.betaLabel` をロケール定義から削除する。
- 画面テストで `BETA` が表示されないことを確認し、回帰を防ぐ。
- メニュー設定のテストで、家計簿項目にバッジがないことを確認する。
- テストマトリクス初期データのテストで、家計簿カテゴリが「実装済」バッジになることを確認する。
- ドキュメントの見出し・目次リンクは表記変更後のアンカーに一致させる。

## 検証

- `BudgetPage` のテストで家計簿の見出しは表示され、`BETA` バッジがないことを確認する。
- テストマトリクス初期データのテストで、家計簿カテゴリが「実装済」バッジになることを確認する。
- `npm run verify` を実行する。

## 関連知見

- L-015: UI から要素を外しても、既存データを暗黙に変更しない。`budgetTexts.page.betaLabel` は `BudgetPage` の表示だけで使われ、保存処理やデータ型には含まれないことを確認済みのため、今回の変更は表示とドキュメントだけに留める。
- L-057: 条件付きで拒否する操作では理由を示す。今回は操作の拒否を追加しない。
- L-060: 組み立て役の配線漏れをテストする。画面コンポーネントのテストで、バッジが描画されないことを固定する。
