# 不具合報告のタイトル入力削除（Issue #182）

## 目的

タイトル入力欄を削除し、内容と任意の再現手順だけで送信する。

## 決めたこと

- フォーム、ページ配線、入力状態、送信フックから title / setTitle を削除する。送信引数は description と stepsToReproduce のみ。
- API の任意 title、保存ペイロードの空文字 title、Firestore ルール、サーバーでの既存タイトル優先と説明先頭50文字の自動生成は維持する。既存データは変更しない。
- タイトル欄専用ラベルとプレースホルダーを削除する。共通入力検証の titleTooLong は互換用に残す。
- 成功時リセット、失敗時入力保持、内容必須・内容と再現手順の長さ検証は維持する。
- 依存追加やタイトル生成ロジック追加は行わない。

## 検証

タイトル欄がないこと、内容だけで送信でき title 引数がないこと、保存時の空 title、既存自動生成をテストで確認。全体検証も実行する。

## 知見

L-015: UI削除で保存済み報告を変更しない。L-060: ページから送信への配線を検証。L-048: 既存自動生成を利用。
