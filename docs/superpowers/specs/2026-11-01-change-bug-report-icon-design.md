# 不具合報告メニューのアイコン変更 設計書（Issue #190）

## 背景・目的

不具合報告メニューのアイコンが虫（🐛）で、虫が苦手な利用者に不快感を与える。虫を連想しないアイコンへ変更する。

## 要件

1. ヘッダーメニューの `bug-report` 項目のアイコンを 🐛 から 📣 に変更する（`src/config/locales/ja.json`）。
2. 虫の絵文字（🐛）を UI に表示しない。
3. 回帰防止のテストを追加する（`src/config/__tests__/index.test.ts`）。
4. ドキュメントのアイコン記載を同期する（`docs/04-reference/README.md` の機能一覧、`docs/04-reference/features.md` の目次・見出し・メニュー説明・メニュー ID 表）。

## 範囲外

- メニューの ID（`bug-report`）・ラベル（「不具合を報告」）・ルート・Firestore コレクション名（`bugReports`）・GitHub Issue のラベル（`bug`）は変更しない（内部識別子であり利用者の目に触れない／仕様変更を伴う）。
- 他メニューのアイコンは変更しない。

## 決めたこと

- 代替アイコンは 📣（意見・要望を伝える意味で、既存メニュー 18 件と重複しない）。推奨案を採用。
- `features.md` の目次リンクのアンカー（`#-不具合報告`）は絵文字が除去されるため変わらない。リンク文言と見出しの絵文字のみ更新する。

## テスト方針

- `menuConfig.menuItems` から `bug-report` を取得し、存在（`toBeDefined`）を固定したうえで、アイコンが 📣 であり 🐛 でないことを検証する（L-662 反映: 探索結果の undefined による偽陽性防止）。
