# 不具合報告の画像リンクを短時間で失効させる

起票時に、画像オブジェクトに対する読み取り専用の Cloud Storage V4 署名付き URL を発行する。URL は発行から 15 分で失効する。カード本文でその期限を案内する。期限内にリンクを持つ人は画像を開けるため、カード閲覧権限の取り消しがリンクに反映されるまでの時間は最大 15 分となる。起票済みカードからの再発行は行わない。

署名前に画像の Firebase ダウンロードトークンをすべて削除し、`Cache-Control: private, no-store, max-age=0` を設定する。変更はオブジェクトの世代・メタ世代を照合し、他のメタデータを保持する。更新後に同じ世代のトークン不在とキャッシュ設定を再取得して確認する。画像は対象の世代に限定して署名する。メタデータ取得・更新・署名の失敗時はリンクを出さず、既存の失敗注記で起票を継続する。ログへ URL やトークンを出さない。

既発行リンクは、旧・新の報告画像専用プレフィックスを対象とする移行コマンドで失効させる。コマンドは既定で確認のみとし、適用を明示した場合だけ同じメタデータ更新を行う。先に旧トークンの発行を停止し、直接アップロードと再発行を防ぐ Storage ルールを公開する。対象バケットと実行権限を確認してから適用する。移行には `storage.objects.list` も必要。署名用サービスアカウントには対象オブジェクトの読み取りと自身の `iam.serviceAccounts.signBlob` が必要。メタデータを更新する実行主体には対象オブジェクトの `storage.objects.update` が必要。バケットと対象オブジェクトの匿名読み取りは IAM と ACL で拒否する。

報告本文・画像データ・既存の保管期間は維持する。取得済みのコピーと既存キャッシュの消去は保証できない。

移行の検証では既存 URL が移行前に開けて移行後は拒否されること、無署名の直接 URL が拒否されること、署名付き URL が期限内だけ開けることをそれぞれ確認する。
