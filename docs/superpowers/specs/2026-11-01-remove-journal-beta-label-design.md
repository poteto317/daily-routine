# ジャーナルの Beta 表記削除（Issue #195）

## 目的

ジャーナル機能が正式機能になったため、利用者に表示するジャーナルの Beta 表記を削除する。

## 対象

- ヘッダーメニューのジャーナル項目に設定している `BETA` バッジ（`badge` オブジェクト）を削除する（`src/config/locales/ja.json`）。
- テストマトリクス画面のジャーナルカテゴリ（`src/features/test-matrix/initialData.ts`）に設定している `BETA` バッジ（`{ text: "BETA", color: "bg-orange-500" }`）を、既存の正式機能と同じ「実装済」バッジ（`{ text: "実装済", color: "bg-green-500" }`）へ変更する。
- `docs/03-testing/test-matrix.md` のジャーナル見出しを `## 3. ジャーナル（Journal）🔶` から `## 3. ジャーナル（Journal）✅` に変更する。個別のテスト項目の状態は、実装完了・安定性を改めて検証する範囲ではないため変更しない。
- `docs/04-reference/features.md` のジャーナルセクションの技術仕様に `- ステータス: 正式機能` を追記する（家計簿セクションと同様）。
- 各テストファイルで検証を追加・更新する:
  - `src/config/__tests__/index.test.ts`: ジャーナルメニュー項目に `badge` プロパティが存在しないことをテストする。
  - `src/features/test-matrix/__tests__/initialData.test.ts`: ジャーナルカテゴリのバッジが「実装済」であることをテストする。
  - `src/features/journal/__tests__/JournalPage.test.tsx`: 画面に `BETA` バッジや表記が表示されないことをテストする。

## 対象外

ジャーナル以外の機能・設定・開発用の `Beta` 表記は変更しない。特に、通知の実験的機能、ポモドーロ、作業記録、運動・食事・体重記録の表記は維持する。

## 決めたこと

- 画面テストで `BETA` が表示されないことを確認し、回帰を防ぐ。
- メニュー設定のテストで、ジャーナル項目にバッジがないことを確認する。
- テストマトリクス初期データのテストで、ジャーナルカテゴリが「実装済」バッジになることを確認する。
- データ構造・型定義・保存処理（LocalStorage や Firestore）には一切変更を加えない。表示とドキュメントの変更に留める。

## 検証

- `src/config/__tests__/index.test.ts` でジャーナルメニューにバッジがないことを確認する。
- `src/features/test-matrix/__tests__/initialData.test.ts` でジャーナルカテゴリが「実装済」バッジになることを確認する。
- `src/features/journal/__tests__/JournalPage.test.tsx` でジャーナルの見出しは表示され、`BETA` バッジがないことを確認する。
- 全単体テスト（`npm test`）が PASS することを確認する。
- プロジェクトの検証コマンド群（Prettier, ESLint, TypeScript 型チェック, Next.js 本番ビルド）を実行し PASS することを確認する。

## 関連知見

- L-015: UI から要素を外しても、既存データを暗黙に変更しない。ジャーナルのデータ型や保存処理には含まれないことを確認済みのため、今回の変更は表示とドキュメントだけに留める。
- L-057: 条件付きで拒否する操作では理由を示す。今回は操作の拒否を追加しない。
- L-060: 組み立て役の配線漏れをテストする。メニュー設定、テストマトリクス初期データ、画面コンポーネントのテストで、バッジが描画されないことを固定する。
