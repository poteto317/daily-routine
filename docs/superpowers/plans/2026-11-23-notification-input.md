# 通知登録の読み取り検証

[設計](../specs/2026-11-23-notification-input-design.md) に従い、L-556 と L-017 を適用する。

1. 現行の通知スケジューラの処理テストで、正常・不正・正常の順に登録を渡す。不正なルーティンがある登録全体を飛ばし、前後の登録を配信することを確認する。抽出処理の境界値もテストする。
2. 同期のトークンとルーティンの既存スキーマを共通モジュールへ移す。読み取り側は同じ制約で検証し、読み取り済みの正常な追加フィールドを保持する。配信・履歴処理は維持する。
3. 関連テスト、全体テスト、Functions とアプリのビルドを実行する。

境界テストはトークン・配列・要素の型と旧 holidayMode を含める。追加フィールドの保持は読み取り側だけに適用する。
