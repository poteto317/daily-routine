# セットアップガイド

プロジェクトを始めるための初期セットアップドキュメントです。

## 📚 ドキュメント一覧

### 環境構築

- **[SETUP_CHECKLIST.md](./SETUP_CHECKLIST.md)** - プロジェクトのセットアップ手順チェックリスト
  - Node.js、Firebase、Vercelのインストール
  - 環境変数の設定
  - 依存関係のインストール
  - ローカル開発環境の起動

### クラウド機能

- **[SYNC_SETUP.md](./SYNC_SETUP.md)** - クラウド同期機能のセットアップガイド
  - Firebase Firestoreの設定
  - セキュリティルールの設定
  - 同期機能の使い方

### 開発環境

- **[vscode_extensions.md](./vscode_extensions.md)** - 推奨VSCode拡張機能リスト
  - 必須ツール
  - 開発体験向上ツール
  - 推奨設定

## 🚀 セットアップの流れ

1. **環境構築** → [SETUP_CHECKLIST.md](./SETUP_CHECKLIST.md) を順番に進める
2. **開発環境** → [vscode_extensions.md](./vscode_extensions.md) で拡張機能をインストール
3. **クラウド機能** → [SYNC_SETUP.md](./SYNC_SETUP.md) でFirebase設定（オプション）
4. **次のステップ** → [開発ガイドライン](../02-development/) でコーディング規約を確認

## 💡 ヒント

- 初めての方は **SETUP_CHECKLIST.md** から始めてください
- クラウド同期を使わない場合、**SYNC_SETUP.md** はスキップして構いません
- VSCode以外のエディタを使用する場合、**vscode_extensions.md** は参考程度にご覧ください
